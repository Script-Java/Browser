# Security policy

## Reporting a vulnerability

Please report it privately: open this repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue.

Say what's affected, how to reproduce it, and what an attacker gains. A proof of concept against your own deploy helps; please don't test against other people's servers.

## What's in scope

- The server and the home-screen app (`app/`), at the latest commit on `main`
- The desktop app (`desktop/`), at the latest release
- Known limits listed in `SECURITY-GAPS.md` ("What's left, and why") are already public. A way to make one of them worse than described there is in scope.
